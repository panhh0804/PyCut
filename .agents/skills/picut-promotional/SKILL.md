# 宣传推广类视频制作

## 核心原则

1. **全面覆盖**：联网搜索品牌/产品信息，确保宣传内容准确完整
2. **情感共鸣**：建立情感连接，让观众"感受"而不仅是"知道"
3. **行动号召**：每个视频都要有明确的CTA（Call to Action）
4. **信任构建**：用事实、数据、证言建立可信度

## 视频结构模板

### 模板A：品牌故事型（30-60秒）
```
镜头1 [0-5秒]  → 品牌愿景/使命（情感开场）
镜头2 [5-15秒] → 痛点/需求（"你是否遇到过..."）
镜头3 [15-30秒] → 解决方案/产品展示
镜头4 [30-45秒] → 用户证言/数据背书
镜头5 [45-60秒] → 行动号召 + 品牌slogan
```

### 模板B：产品功能型（20-40秒）
```
镜头1 [0-3秒]  → 核心卖点一句话
镜头2 [3-12秒] → 功能演示/对比
镜头3 [12-25秒] → 技术优势/独特性
镜头4 [25-35秒] → 使用场景展示
镜头5 [35-40秒] → 价格/优惠 + 购买引导
```

### 模板C：活动宣传型（15-30秒）
```
镜头1 [0-3秒]  → 活动亮点/数字（"1000+品牌参与"）
镜头2 [3-10秒] → 活动内容/看点
镜头3 [10-20秒] → 嘉宾/嘉宾阵容
镜头4 [20-25秒] → 时间地点
镜头5 [25-30秒] → 立即报名/扫码
```

### 模板D：社会证明型（25-45秒）
```
镜头1 [0-4秒]  → 权威数据（"100万用户的共同选择"）
镜头2 [4-12秒] → 多角度证言（3个真实用户）
镜头3 [12-25秒] → 媒体报道/获奖情况
镜头4 [25-35秒] → 行业地位/市场份额
镜头5 [35-45秒] → 加入我们 + CTA
```

## 视觉设计规范

### 配色方案
根据品牌调性选择：
- **科技/创新**：`#2196F3`（蓝）、`#00BCD4`（青）、`#E91E63`（粉）
- **高端/奢华**：`#FFD700`（金）、`#000000`（黑）、`#FFFFFF`（白）
- **活力/年轻**：`#FF5722`（橙）、`#FF9800`（黄）、`#4CAF50`（绿）
- **专业/可靠**：`#1565C0`（深蓝）、`#37474F`（深灰）
- **温暖/亲和**：`#FF7043`（暖橙）、`#8D6E63`（棕）

### 字体选择
- **品牌标题**：`Playfair Display`、`Didot`（高端感）
- **产品名称**：`Montserrat Bold`、`Poppins Bold`（现代感）
- **正文信息**：`Open Sans`、`Noto Sans SC`（可读性）
- **数据数字**：`Roboto Mono`、`DIN Condensed`（专业感）

### 视觉元素
| 元素类型 | 用途 | 实现方式 |
|---------|------|---------|
| 产品图 | 核心展示 | `image` layer + `scale` 动画 |
| 用户头像 | 证言 | `image` + 圆形裁剪 |
| 奖章/徽标 | 信任背书 | `image` + `badge` |
| 数据图表 | 实力展示 | `chart` + `count` 动画 |
| 二维码 | 行动入口 | `image` + 扫描引导 |
| 背景视频 | 氛围营造 | `particles` 或渐变 |

## 动画规范

### 品牌元素动画
- **Logo出现**：`scale` + `fade`（从无到有，从小到大）
- **产品展示**：`rise`（产品升起）或 `slide-right`（产品滑入）
- **数据展示**：`count`（数字跳动）+ `rise`（柱状图生长）
- **文字信息**：`fade` 或 `slide-left`（信息逐步呈现）
- **CTA按钮**：`pulse`（脉冲吸引注意力）

### 节奏控制
```
情感铺垫 → [慢节奏 fade/slide]
产品展示 → [中节奏 rise/scale]  
数据背书 → [快节奏 count/draw]
行动号召 → [强节奏 pulse/scale]
```

## 文案风格

### 开场公式
```
情感共鸣：
"每一个[目标用户]，都值得更好的[价值]"
"当[痛点场景]发生时，你需要[解决方案]"

数据冲击：
"[数字]万用户的选择"
"[奖项]获得者——[品牌名]"

悬念引导：
"接下来这30秒，可能会改变你对[领域]的认知"
"这个[产品]凭什么能做到[成就]？"
```

### 核心信息结构
1. **痛点**（0-20%）：用户面临的问题/需求
2. **方案**（20-50%）：产品/品牌如何解决
3. **证明**（50-80%）：数据、证言、权威背书
4. **行动**（80-100%）：明确的下一步

### CTA设计
```
直接型："立即购买"、"马上体验"、"免费试用"
紧迫型："限时优惠"、"仅剩XX个名额"、"今天下单立减"
社交型："加入XX万用户"、"和XX一起"
好奇型："了解更多"、"看看效果"、"亲自体验"
```

## 联网搜索指南

使用 `search_media` 时必须搜索以下信息：
1. **品牌/产品官网**：获取准确的产品信息、规格、价格
2. **用户评价**：真实用户反馈、评分
3. **媒体报道**：权威媒体的报道和评测
4. **竞品对比**：差异化优势
5. **行业数据**：市场地位、市场份额

### 推荐搜索词
```
"[品牌名] official website"
"[品牌名] user reviews"
"[品牌名] news"
"[产品名] vs [竞品名]"
"[行业] market share 2024"
```

- ✅ 真实用户证言

## 常见错误避免

### ❌ 不要这样做
- 只有产品功能，没有情感连接
- 数据堆砌，没有故事线
- CTA不明确或太弱
- 没有信任背书
- 文案太长，信息过载

### ✅ 应该这样做
- 功能+情感并重
- 数据服务于故事
- CTA清晰有力
- 用多个信任元素
- 精简文案，突出重点
