# 财经新闻类视频制作

## 核心原则

1. **数据为王**：所有观点必须有数据支撑，数字是最有说服力的语言
2. **爆点前置**：前3秒必须抓住注意力，用最震撼的数据或结论开场
3. **节奏紧凑**：财经受众时间宝贵，每秒都要传递价值
4. **可信度高**：使用权威数据源，避免主观臆断

## 视频结构模板

### 模板A：市场速报型（15-30秒）
```
镜头1 [0-3秒]  → 爆点数据大字报（红绿配色，数字跳动动画）
镜头2 [3-10秒] → 关键指标图表（折线图/柱状图，标注关键点）
镜头3 [10-20秒] → 原因分析（2-3个要点，图标+文字）
镜头4 [20-30秒] → 结论/操作建议 + 免责声明
```

### 模板B：深度解读型（30-60秒）
```
镜头1 [0-5秒]  → 悬念式开场（"这个信号意味着什么？"）
镜头2 [5-15秒] → 数据全景（多维度数据对比）
镜头3 [15-30秒] → 历史对比（类似情况回顾）
镜头4 [30-45秒] → 专家观点/机构预测
镜头5 [45-60秒] → 投资者行动指南
```

### 模板C：个股分析型（20-40秒）
```
镜头1 [0-3秒]  → 公司名+当日涨跌幅（视觉冲击）
镜头2 [3-12秒] → 核心财务指标（PE、营收、利润）
镜头3 [12-25秒] → 技术面/基本面分析图表
镜头4 [25-35秒] → 机构评级/目标价
镜头5 [35-40秒] → 风险提示
```

## 视觉设计规范

### 配色方案
- **牛市/上涨**：`#00C853`（绿）、`#1B5E20`（深绿背景）
- **熊市/下跌**：`#FF1744`（红）、`#B71C1C`（深红背景）
- **中性/分析**：`#2196F3`（蓝）、`#0D47A1`（深蓝背景）
- **警示/风险**：`#FF9100`（橙）
- **背景色**：`#0A0E17`（深色科技感）、`#FFFFFF`（浅色专业感）

### 字体选择
- **数据数字**：`DIN Condensed`、`Roboto Mono`、`JetBrains Mono`（等宽，易读）
- **标题**：`Inter Bold`、`Noto Sans SC Bold`
- **正文**：`Inter Regular`、`Noto Sans SC Regular`

### 图表类型选择
| 数据类型 | 推荐图表 | 说明 |
|---------|---------|------|
| 时间序列 | 折线图 | 股价、指数走势 |
| 对比数据 | 柱状图 | 营收、利润对比 |
| 占比数据 | 饼图/环形图 | 仓位、行业分布 |
| 多维度 | 雷达图 | 综合评分 |
| 关键指标 | 大数字+趋势箭头 | PE、涨跌幅 |

## 动画规范

### 数据动画
- **数字跳动**：使用 `motion.preset: 'count'` 实现数字从0到目标值的动画
- **折线绘制**：使用 `motion.preset: 'draw'` 实现线条逐渐绘制效果
- **柱状图生长**：使用 `motion.preset: 'rise'` 配合 `height` 百分比动画

### 转场效果
- 数据场景间：`fade` 或 `wipe`，保持信息连贯
- 观点切换：`slide-left` 或 `slide-right`，表示逻辑推进
- 结论强调：`scale` + 放大效果

## 文案风格

### 标题公式
```
[爆点数字] + [核心事件] + [影响/悬念]
例：
"暴跌800点！美股发生了什么？"
"营收翻3倍！这家芯片股为何暴涨"
"降息25个基点，对你的钱包意味着什么"
```

### 叙事节奏
1. **开场**：用最震撼的数据或结论
2. **展开**：2-3个支撑论点，每个论点配一个数据
3. **收尾**：可操作的建议或悬念

### 语言禁忌
- ❌ 避免：可能、大概、也许、据说
- ✅ 使用：数据显示、据统计、根据XX报告
- ❌ 避免：必涨、必跌、稳赚
- ✅ 使用：值得关注、风险与机会并存

## 搜索素材指南

使用 `search_media` 时的推荐查询：
- `stock market trading floor`
- `financial charts analysis`
- `Wall Street skyline`
- `currency exchange`
- `economic data visualization`
- `business technology abstract`

## 免责声明模板

每个财经视频必须在结尾包含：
```
本视频仅供参考，不构成投资建议。投资有风险，入市需谨慎。
数据来源：[具体来源]
```
