# 教育科普类视频制作

## 核心原则

1. **好奇心驱动**：用反直觉的事实或悬念开场，激发"为什么"的欲望
2. **循序渐进**：从已知到未知，从简单到复杂，每步只引入一个新概念
3. **可视化优先**：抽象概念必须用图形/动画具象化，让观众"看见"原理
4. **记忆锚点**：每个知识点配一个生活化的类比或例子

## 视频结构模板

### 模板A：悬念解答型（30-60秒）
```
镜头1 [0-5秒]  → 反直觉问题（"为什么天空是蓝色的？"）
镜头2 [5-15秒] → 常见误解（"很多人以为是反射..."）
镜头3 [15-35秒] → 原理可视化（动画演示瑞利散射）
镜头4 [35-50秒] → 生活延伸（"所以夕阳是红色的..."）
镜头5 [50-60秒] → 互动问题（"你知道海水为什么是蓝色吗？"）
```

### 模板B：步骤拆解型（20-40秒）
```
镜头1 [0-3秒]  → 最终效果展示（"这个魔术是怎么做到的？"）
镜头2 [3-10秒] → 第一步原理（关键概念A）
镜头3 [10-20秒] → 第二步原理（关键概念B）
镜头4 [20-30秒] → 组合效果（A+B的化学反应）
镜头5 [30-40秒] → 举一反三（还能怎么用？）
```

### 模板C：对比认知型（25-45秒）
```
镜头1 [0-4秒]  → 两个看似相同的事物（"这两张图有什么区别？"）
镜头2 [4-12秒] → 揭示关键差异（放大细节）
镜头3 [12-25秒] → 差异背后的原因（原理讲解）
镜头4 [25-35秒] → 实际应用（"利用这个原理..."）
镜头5 [35-45秒] → 有趣的事实延伸
```

## 视觉设计规范

### 配色方案
- **科学/理性**：`#2196F3`（蓝）、`#0D47A1`（深蓝）- 适合物理、数学、计算机
- **自然/生命**：`#4CAF50`（绿）、`#1B5E20`（深绿）- 适合生物、生态、医学
- **人文/历史**：`#FF9800`（橙）、`#E65100`（深橙）- 适合历史、文学、社会
- **神秘/探索**：`#9C27B0`（紫）、`#4A148C`（深紫）- 适合宇宙、量子、未解之谜
- **清新/日常**：`#00BCD4`（青）、`#006064`（深青）- 适合生活技巧、日常科学

### 字体选择
- **公式/代码**：`STIX Two Math`、`KaTeX_Main`、`JetBrains Mono`
- **标题**：`Noto Sans SC Bold`、`Source Han Sans Bold`
- **正文/标注**：`Noto Sans SC Regular`、`Inter Regular`
- **手写感**：`Caveat`、`Patrick Hand`（适合轻松科普）

### 可视化元素
| 概念类型 | 可视化方式 | 动画效果 |
|---------|-----------|---------|
| 流程/步骤 | 流程图、箭头连线 | `draw` 逐步绘制 |
| 数学公式 | KaTeX渲染 + 高亮变化部分 | `reveal` 逐项出现 |
| 物理过程 | 粒子系统、轨迹线 | `particles` + `line` |
| 数据对比 | 柱状图、雷达图 | `rise` 生长动画 |
| 结构拆解 | 分层爆炸图、透视图 | `scale` + 位移 |
| 时间变化 | 时间轴、折线图 | `draw` 绘制过程 |

## 动画规范

### 知识点展开节奏
- **问题**：`fade` + `scale`（放大问题）
- **误解**：`slide-left`（表示"错误方向"）
- **正确答案**：`rise` + `scale`（"揭示"效果）
- **原理演示**：`draw`（逐步绘制）或 `reveal`（逐步展现）
- **延伸应用**：`float`（"思考延伸"感）

### 公式动画
```json
{
  "motion": {
    "preset": "draw",
    "delayFrames": 12,
    "durationFrames": 60,
    "intensity": 1.5
  }
}
```

### 粒子效果（用于物理/化学演示）
```json
{
  "id": "particles-demo",
  "type": "particles",
  "content": "24",
  "style": { "color": "#2196F3" },
  "motion": { "preset": "float", "delayFrames": 30, "durationFrames": 90 }
}
```

## 文案风格

### 开场公式
```
反直觉提问：
"为什么[常识]其实是错的？"
"你知道[日常事物]背后藏着什么秘密吗？"
"[数字]个[事物]中，只有1个能[结果]——为什么？"

数据冲击：
"[数字]秒——这是[过程]所需的时间"
"如果把[事物]放大[倍数]倍，你会看到..."

悬念设置：
"接下来这个原理，可能会颠覆你的认知"
"这个看似简单的现象，科学家研究了200年"
```

### 讲解节奏
1. **引入**（0-10%）：用问题或现象抓住注意力
2. **铺垫**（10-30%）：建立已知基础，避免认知断层
3. **核心**（30-70%）：逐步展开原理，每个步骤配可视化
4. **巩固**（70-90%）：用例子或类比强化理解
5. **延伸**（90-100%）：留下思考空间或行动号召

### 语言禁忌
- ❌ 避免：专业术语堆砌、一上来就定义概念
- ✅ 使用：生活化类比、"想象一下"、"就像..."
- ❌ 避免：过于简化的错误类比
- ✅ 使用：精确但易懂的表述、"严格来说..."

## 公式可视化指南

### 支持的公式格式
- LaTeX语法：`E = mc^2`、`\frac{a}{b}`、`\sqrt{x}`
- 数学符号：`∑`、`∫`、`∂`、`∞`
- 希腊字母：`α`、`β`、`γ`、`θ`、`π`

### 公式动画策略
1. **逐项出现**：公式各部分按讲解顺序依次显示
2. **变量高亮**：讲解某个变量时，其他部分变暗，当前变量加颜色强调
3. **数值代入**：抽象公式 → 代入具体数字 → 显示结果
4. **几何解释**：公式旁边配几何图形，展示公式的几何含义

## 记忆点设计

每个视频至少包含一个"记忆锚点"：
- **类比**："原子就像一个微型太阳系"
- **数字**："光从太阳到地球需要8分20秒"
- **反差**："蚂蚁能举起自身体重50倍的物体"
- **互动**："现在试试用手捂住屏幕..."
