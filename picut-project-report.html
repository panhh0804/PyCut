状态设计

VideoSpec 是唯一事实源

不是“聊天记录 + 一坨不可逆结果”，而是一份可校验、可版本化、可编译的视频描述。

一次修改，四处一致

UI 与 Agent 的动作都提交 ChangeSet，随后由同一 revision 驱动画布、时间线、Inspector 与渲染器。

Canvas画面与播放头
Timeline轨道、时长、分割
InspectorScene / Style / Motion
Renderer同源双引擎消费
UI → VideoSpec → Agent／Agent → Tools → VideoSpec → UI
版本、修订与 ChangeSet 让人机协作有共同语境06
